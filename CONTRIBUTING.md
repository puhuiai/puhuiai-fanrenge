# Contributing

Thank you for testing and reporting problems with 普惠AI products.

## Bugs and feature requests

Open an issue in the product repository and include:

- product version
- operating-system version
- clear reproduction steps
- expected and observed behavior
- screenshots or logs with private data removed

## Pull requests

These product repositories are proprietary unless their LICENSE states otherwise. Code pull requests may be closed without merge. Documentation corrections and reproducible bug reports are welcome through Issues.

## Security issues

Do not post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
