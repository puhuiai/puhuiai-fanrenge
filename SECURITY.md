# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected security issue in a public issue.

Use GitHub private vulnerability reporting for this repository when available. If it is not enabled, contact 普惠AI through **https://puhuiai.com.cn** and include:

- affected product and version
- Windows or Android version
- reproduction steps
- expected and observed behavior
- relevant logs or screenshots with personal data removed

We will review the report and coordinate disclosure after the issue is understood and a fix or mitigation is available.

## Scope

This repository contains product documentation and release assets. Third-party libraries, model providers, and operating-system components should also be reported to their respective vendors.
