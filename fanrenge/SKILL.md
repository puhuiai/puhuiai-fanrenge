# 普惠AI · 需求翻译层（小龙虾宿主版）

**一句话**：宿主听得懂大白话的第一步 —— 自动追问补齐 → 输出标准化任务包 → 交给下游执行 Agent。
**零算力**：纯规则，不调用任何大模型，离线可跑，**不占你的 token**。

## 怎么调用（3 行）

```python
import sys
sys.path.insert(0, r'E:\LobsterPro3.0\workspace')      # 这一层里能看到 fanrenge 文件夹
from fanrenge import run_once, Session

r = run_once("帮我做一条 90 秒的房产短视频")
if r['state'] == 'ask':        # 还缺参数 → 把 r['question'] 原样问用户，拿到答复塞回 continue
    r2 = Session(r['session_id']).ask(用户答复)
elif r['state'] == 'done':     # 出包 → r['package'] 给下游；r['human'] 是给老板看的大白话
    print(r['human'])
```

## 能力
- **13 个行业模板**：短视频 / 文案写作 / 网页小程序 / 电商美工 / PPT制作 / 数据分析 / 基础APP开发 / 营销策划 / 招聘就业 / 教育培训 / 医疗健康科普 / 法律财税 / 餐饮零售
- **综合模具（v1.1 新增）**：所有任务统一套用的 8 环节骨架（目标→环境→工具→澄清→拆步→约束→验收→下游复盘）+ 通用红线/验收/下游，存在 `templates.json` 的 `_模具` 段
- **行业标准包（v1.1 新增）**：`_行业包` 段，14 个包只写差异（工具 / 硬约束 / 行业验收 / 合规）；支持 `继承` 共享基础包（如 `编程开发`）；自由模式按 `match` 关键词猜行业包
- 无匹配模板时**自动降级**为"行业通用 → 自由模式"，**自由模式同样输出 8 环节骨架**（改造前只有 4 句笼统话）
- 任务包字段：目标 / 已知参数 / 待下游确认 / 分步任务 / 验收标准 / 限制条件 / 输出规范 / 下游执行顺序 / 匹配 / 适用工具（行业标准）/ 合规提示（行业标准）

## 与"普惠AI EveryAgent（完整引擎版）"的关系
插件 = **需求翻译层**（听懂人话→任务包）；EveryAgent = **执行引擎**（术语库/6 阶段流水线/OPC）。
两者可串联：大白话 → 本插件(追问/出包) → EveryAgent(执行) → 产出。


## v1.1 综合模具 + 行业标准（2026-09-24 落地）

改造前 13 个行业 = 13 份模板各自写一遍通用步骤/限制/验收；改造后 **1 套模具 + N 个行业包**：

| 层 | 位置 | 写什么 | 成本 |
|---|---|---|---|
| ① 综合模具 | `templates.json` → `_模具` | 8 环节骨架 + 通用红线/验收/下游 | 1 份，几乎不动 |
| ② 行业标准包 | `templates.json` → `_行业包` | 只写差异：工具/硬约束/行业验收/合规 | 新增 1 行业 6~10 行 |
| ③ 场景模板 | `templates.json` → `templates[]` | 只写差异：槽位/独有步骤/独有验收 | 新增 1 场景约 10 分钟 |

- 引擎侧 API（宿主不用改）：`load_mold()`、`missing_slots(tpl, filled, mold=None, free_mode=False)`、`build_package(text, tpl, filled, cls, templates=None)`、`_effective_pack(templates, industry)`
- 拼装顺序：模具前段 → 模具中段 → 行业包(继承链) → 子域 → 场景 → 模具收尾；步骤编号自动重排 ①②③…
- 命中模板时「完成标准」自动代填 ⇒ **追问轮数与改造前一致**，不会多问；只有自由模式才问
- 「行业 > 子域」：如 `短视频 > 房产` 的红线只作用于房产短视频，不污染整个短视频行业（`房产内容不得夸大学域承诺`）
- 维护铁律：模具里出现行业词即违规；行业包照抄模具句子质检会打回；改动前先备份、改完复跑两个测试 + 覆盖度脚本
- **归类打分（2026-09-24 修复）**：`_score` 带权重——强信号词（HTML/页面/单页/代码/ppt…）×3、泛词（数据/内容/设计/文案…）×0.4、其余按长度；解决「句子里有『数据』就被『数据分析』抢走」
- **自测手段（2026-09-24 补）**：模具 `自测手段_base` 3 条通用 + 环境环节步骤含「做完拿什么自测」；行业包可写 `自测手段`（只写差异）；任务包与大白话输出带「【做完拿什么证明】」
- **应变预案（2026-09-24 补）**：模具 `预案_base` 3 条兜底 + 行业包可写 `预案` 差异；任务包与大白话输出带「【卡住怎么办】」（对应视频2 规划能力的"动态调整"）
- **前置经验检索（2026-09-24 补）**：本地经验台账 `fanrenge/experience.json`（零算力，不调模型）。引擎侧 API：`recall(行业, 场景)` 读回同行业最近的记录、`remember(pkg)` 出包后自动登记（幂等、每行业最多留 50 条、写失败绝不影响出包）；模具第②步即「先查同行业历史任务」；任务包与大白话输出带「【上次同类任务】」
- 验收证据（2026-09-24）：`test_engine.py` **36/36**、`test_autolearn.py` **19/19**、旧包 183 条内容覆盖度「无归属 0 条」、真实编程任务独立复核 16/16

## 增量自学习（Phase3，对应《完整落地思路.docx》第 49/68 行）

规则：**引擎只提炼候选，绝不自动写入模板库**；入库必须人工审核（防垃圾模板污染字典）。

- 触发条件：这次任务**没匹配到任何行业模板**（自由模式 / 通用降级）且已完成出包
- 产出：结果里会多一个字段 `候选模板`：
  ```python
  r = run_once("帮我给楼下的快递驿站写一份合作备忘录草稿", answers=["给快递公司看", "正式一点"])
  # r['候选模板'] = {'id': 'auto_54115', '状态': 'pending（待人工审核）', ...}
  ```
- 宿主建议做法：把 `候选模板` 的存在告诉用户（"这个需求我还没现成模板，已记下来，审核通过后下次就快"），**不要**自己改模板库
- 人工审核命令（宿主或老板直接跑）：
  ```bash
  python -m fanrenge.review --pending                 # 列待审（含来源、出现次数、质检结论）
  python -m fanrenge.review --check  <id>             # 只跑质量闸门
  python -m fanrenge.review --approve <id>            # 通过 → 并入模板库（三级目录自动补 scene）
  python -m fanrenge.review --reject  <id> [理由]     # 驳回 → 进 rejected 可追溯
  ```
- 质量闸门（不合格不许入库）：steps ≥ 4、match 关键词 ≥ 4、required 3~5 个、goal 必须含 `{占位符}`
- 去重：同一需求重复出现时**不重复入队**，而是给 `来源.hits` 累加（体现"这个需求很热"，审核时优先）
